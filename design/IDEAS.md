I would quite like to bolster the early game adventure feeling.

I want to avoid 

Login -> Punch tree -> Get diamonds -> Build / complete game

I want to foster

Login -> Journey around -> Be moved to create with primative / limited tools/materials
    -> Slowly garner more interesting/better tools  <--> REPEAT


This could be achieved by locking away things like the crafting table, making ores/minerals hard to acquire at first.
We could make it so that players can only get drops by using specific items, e.g getting wool using shears, getting meat by using hunting equipment.

I like how matcha includes mud as a technology. With the mud bricks, mud kilns etc.
I think the wooden pickaxe is useless.
